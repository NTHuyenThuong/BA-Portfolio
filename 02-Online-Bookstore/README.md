# Online Bookstore System

## Project Overview

An academic project focused on analyzing and documenting an online bookstore system.

The project covers functional requirements, non-functional requirements, use case analysis, and database modeling.

## My Role

Business Analyst

My main responsibilities included:

- Analyzing and documenting functional requirements
- Defining non-functional requirements
- Identifying system actors and use cases
- Developing use case diagrams
- Documenting use case scenarios
- Analyzing and documenting the database structure
