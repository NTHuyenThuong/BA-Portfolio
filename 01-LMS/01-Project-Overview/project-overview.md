# Project Overview

## 1. Project Name

**Learning Management System (LMS)**

## 2. Project Type

Academic Group Project

## 3. Project Objective

The Learning Management System (LMS) is designed to support teaching and learning activities in an educational environment.

The system aims to provide a centralized platform for managing classes, courses, learning materials, assignments, examinations, attendance, grades, schedules, and learning-related activities.

## 4. Target Users

The main users of the system include:

- Students
- Lecturers
- Training Management Staff
- System Administrators

Each user group has different permissions and functions according to their responsibilities within the system.

## 5. Main Functional Areas

The system covers several major functional areas:

### User & Role Management

- User management
- Role management
- Permission management

### Course & Class Management

- Course management
- Class management
- Student enrollment
- Class information

### Learning Management

- Learning materials
- Assignments
- Examinations
- Homework
- Learning activities

### Attendance & Grade Management

- Attendance management
- Grade management
- Grade tracking
- Learning results

### Schedule Management

- Class schedules
- Learning schedules

### Reporting & Statistics

- Learning statistics
- Class statistics
- Academic performance reports

### Online Learning Integration

The system is designed to support integration with online meeting platforms such as:

- Zoom
- Google Meet

## 6. Business Scope

The project focuses on analyzing and modeling the business processes involved in managing teaching and learning activities.

The BA analysis covers:

- Stakeholder and user identification
- Requirements analysis
- Functional requirements
- Non-functional requirements
- Business rules
- Use Case analysis
- System workflows
- Role and permission analysis
- UML modeling
- Data modeling
