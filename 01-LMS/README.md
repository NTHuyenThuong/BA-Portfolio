# Learning Management System (LMS)

## 1. Project Overview

The Learning Management System (LMS) is an academic group project designed to support teaching and learning activities within an educational environment.

The system provides functions for managing users, courses, learning materials, assignments, examinations, grades, and other learning-related activities.

## 2. My Role

**Role:** Business Analyst

My main responsibilities focused on requirements analysis, business documentation, system modeling, and permission analysis.

## 3. Main Functional Areas

The LMS includes the following major functional areas:

- User Management
- Course Management
- Learning Materials
- Assignment & Examination
- Grade Management
- AI Features
- System Administration
